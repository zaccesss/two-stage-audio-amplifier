# Security Policy

## Scope

This repository is a written engineering report plus Proteus design files. It contains no software, no service and no user data, so there is very little attack surface. In scope:

- Unsafe wiring or component guidance in the report that could create a fire, shock or component damage risk if followed as written

## Out of scope

- General accuracy or style feedback, use a regular issue instead
- Third-party datasheet content referenced from the report, report those to the manufacturer

## Reporting a concern

> [!IMPORTANT]
> Report privately, not in a public issue. Email [eng@isaacadjei.me](mailto:eng@isaacadjei.me) with details. Expect an acknowledgement within a few days.
