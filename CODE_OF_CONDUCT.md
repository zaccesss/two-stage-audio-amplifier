# Code of Conduct

## Standards

This is a personal engineering report shared for reference. Anyone interacting with it through issues or pull requests is expected to be respectful and constructive and to give specific feedback rather than vague criticism.

## Unacceptable behaviour

Harassment, abuse or personal attacks of any kind, spam or off-topic promotion, sharing anyone's private information without consent.

## Enforcement

> [!NOTE]
> Report unacceptable behaviour to [eng@isaacadjei.me](mailto:eng@isaacadjei.me) or via [isaacadjei.me/contact](https://isaacadjei.me/contact). Reports will be reviewed and appropriate action taken, including removing comments or blocking users if necessary.
